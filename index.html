كيفية التشغيل والنشر

1. التثبيت

pip install -r requirements.txt

2. التشغيل المحلي

python app.py

3. التشغيل عبر Gunicorn

gunicorn -w 2 -b 0.0.0.0:5000 app:app

4. متطلبات Chrome

يجب تثبيت Chrome و ChromeDriver في بيئة النشر (Render / Railway) عبر أوامر البناء.
